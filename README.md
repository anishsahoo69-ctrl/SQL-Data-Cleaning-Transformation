# 📊 Mini Project 01 – Data Cleaning & Transformation using SQL

## 📌 Project Overview

This project focuses on cleaning, transforming, and standardizing inconsistent and incomplete data using **MySQL**.

The main objective is to improve data quality by identifying missing values, handling duplicates, correcting inconsistencies, and transforming raw data into a structured and meaningful format.

This project demonstrates practical SQL skills used in real-world data analytics.

## 🎯 Objectives

* Identify and handle missing (NULL) values.
* Clean inconsistent and incorrect data.
* Detect and manage duplicate records.
* Standardize data formats.
* Perform string manipulation.
* Update records using SQL UPDATE statements.
* Apply conditional logic to transform data.
* Improve overall data quality.

## 🛠️ Technologies Used

* **Database:** MySQL
* **IDE:** MySQL Workbench
* **Language:** SQL
* **Dataset:** Customer Database (Classic Models)

## 📚 Skills & SQL Concepts Covered

| SQL Concept    | Description                     |
| -------------- | ------------------------------- |
| SELECT         | Retrieve data from tables       |
| WHERE          | Filter specific records         |
| ORDER BY       | Sort records                    |
| LIKE           | Search using patterns           |
| BETWEEN        | Filter values within a range    |
| IN             | Match multiple values           |
| LIMIT & OFFSET | Control returned records        |
| COUNT()        | Count records                   |
| SUM()          | Calculate total values          |
| AVG()          | Calculate average values        |
| MIN() & MAX()  | Find minimum and maximum values |
| GROUP BY       | Group similar records           |
| HAVING         | Filter grouped results          |
| IS NULL        | Identify missing values         |
| UPDATE         | Modify existing records         |
| DISTINCT       | Identify unique values          |
